# Work-Jatt Webtop extensions

Put wallpapers in `backgrounds/<theme-slug>/`. In the desktop terminal,
run `webtop-link-extensions` after adding files, then choose a wallpaper with
`omarchy-theme-bg-switcher`. Keep personal desktop state under `/config`.

Add `omarchy-menu.jsonc` here to extend the native menu. Reload the desktop if
the menu still shows its previous contents. Existing personal menus take
precedence.
